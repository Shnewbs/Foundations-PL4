# 0.0.2a.R1.3 — Display element list and layer controls

- Open Layers with L or the editor HUD button. Select overlapping elements from a current-page list ordered frontmost first; Shift toggles a selection and Ctrl+A selects the page.
- Move the entire selection forward/backward one layer or to the front/back. Selected and unselected relative order, styling, bindings and geometry remain intact; other pages retain their exact list positions.
- Layer edits use one revision-fenced server transaction and one undo snapshot. Missing, duplicate, stale, other-page and unauthorized selections reject atomically. The existing world-toolbar forward/backward controls now operate on the whole selection.
- Keep the editor active while the layer/arrangement panel is open so acknowledgements and world selection outlines stay current.
- Retain the R1.2 cable fix, now accepted by the user in the modpack.

Native persistence/security tests and exhaustive small-selection order invariants are included. Client visual acceptance for the new layer panel remains pending. This continues roadmap Phase 1; groups, locks/visibility, page tools, layout storage and remaining styles/actions are still open.
