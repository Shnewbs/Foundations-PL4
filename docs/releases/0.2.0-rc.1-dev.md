# Legacy RC development: basic readers and displays

Unpublished development build for Minecraft 1.6.4. This is not a stable RC.

Adds item, fluid, energy and network readers plus a four-line physical display. Each reader has its own recipe: cable + glass + iron ingot / bucket / gold ingot / compass; the display uses cable + glass + paper. Sneak-click a reader face to select its adjacent target. Link readers and displays using same-owner cables. Click a display to select the next reader; sneak-click a horizontal face to orient it.

Displays start private. The owner can use `/pl4legacy display x y z show` to publish readings to nearby players and `hide` to clear them. Inspection remains available to the owner or an operator within eight blocks. Server packets contain the bounded public lines and facing only. Readings refresh once per second, scan loaded targets within configured limits, and never extract, insert or simulate resources. External providers may themselves be expensive; no performance improvement is claimed without measurement.

Existing item/fluid/energy escrow remains schema 3. Reader settings are additive; old saves load private. Do not downgrade worlds containing the new block IDs. On 1.6.4, ownership is the legacy player name, energy readings use PL4 internal units and no RF/EU/FE equivalence is inferred. Its new configurable block IDs default to 3509–3513.

The exact candidate must pass 112 native scenarios and a separate production-only boot. Graphical acceptance, installed optional mods, migration from copied real worlds, multiplayer and measured large-network performance remain pending. Full modern editor/multipart/wireless-storage parity is still incomplete.

A separate migration fixture creates and saves a world using the checksum-verified immutable preview.3 runtime, then opens the same world using this candidate. It verifies resource escrows, storage, ownership, default-private settings and new monitoring of the existing inventory. This generated-world gate does not replace copied user-world or installed-mod acceptance.
