# Foundations PL4 1.18.1 — RC development snapshot

Unpublished development build preparing a common performance baseline. This is not a stable release or a cleared release candidate.

Includes topology-owned network membership/storage indexes and per-cycle endpoint identity reuse. The compact Wireless Storage layout fix is carried forward. Transfer status uses the same channel/direction decision as actual routing. Foreign item mutations now persist uncertainty before executing; interrupted or invalid results remain quarantined across reloads and part removal. Saved item escrow preserves full integer counts and unresolved payloads. Existing healthy saves keep their values. Fluid, FE and native energy mutations also fence interrupted or invalid results; unresolved saved fluid payloads remain opaque. Wireless Storage stages offhand deposits in node escrow before foreign insertion and fences uncertain player delivery. Target-specific loader APIs, routing, rates, filters and ownership are retained. These additive safety fields require forward migration acceptance; do not downgrade a world with unresolved transactions.

Native build/scenario evidence must identify this exact source and artifact. Installed optional providers, actual client UI, live multiplayer, world migration and repeatable large-network performance acceptance remain open. No measured TPS/MSPT or memory improvement is claimed. Legacy subset ports do not inherit these changes or their results.
