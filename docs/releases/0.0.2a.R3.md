# Foundations PL4 0.0.2a.R3 — editor organization and controlled routing

- Group/ungroup, lock/unlock and hide/show display elements from Layers. World selections move groups together; hidden elements stay available in Layers. Authorized undo/redo restores element metadata.
- Add backgrounds and borders, name the eight pages, and configure clickable page links. Server-resolved clicks respect reach, ownership, canvas protection and frontmost visible layers.
- Separate input/output channels on Nodes and Transfer Nodes. Routes match exact case-sensitive names; blank preserves the existing default pool. Channel edits require empty escrow.
- Rotate equal-priority drivers and destinations by network cycle, independently of source inventory slots. Buffered drivers retain priority within each transfer phase.
- Inspect and remove individual saved links on Arrays, Entity Nodes and wireless receivers without clearing the whole list.
- Configure Clock pulse width and phase, pause/resume it, or reset its cycle. Timing remains limited by the server sampling interval.
- Add regression coverage for metadata persistence, permission checks, clickable pages, channel isolation, fairness, stable link deletion and Clock settings. Refresh the in-game Field Guide.

## Scope and world compatibility

This is a substantial R3 feature batch, not full PL2 parity. Complete directional filter semantics, Signaller statement lists, remote-storage UI, remaining component parity and installed optional power-mod acceptance remain open. ADD/REMOVE remains peer-only. Real-client visual and live multiplayer acceptance are still needed.

New world data is optional within host schema 2. Existing worlds retain default behavior. Older releases discard the new metadata and channels; downgrading can reconnect routes that R3 separates. Keep a world backup. Page names are saved on displays but are not part of element-only undo/template snapshots.
