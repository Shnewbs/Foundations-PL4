# Foundations PL4 1.6.4 experimental legacy preview 1

**Initial native item-transport subset, NOT full modern 0.2a parity. Further API testing is still required.**

The build uses the available Forge 9.11.1.960 development API and produces Java 7 bytecode. The release gate separately exercises that exact remapped runtime on the published **Forge 9.11.1.1345 / Java 7** server. There is no Forge 960 installer/universal runtime claim.

Adds craftable cable/export/import hosts, name-based legacy ownership, loaded physical networks, sided native inventories, bounded transfer work, redstone pause and saved transfer buffers. Native configuration, actual registered-recipe command lookup and owner-checked inspection provide built-in alternatives without mandatory viewer or tooltip mods.

Release publication requires portable rule regressions, remapped runtime packaging, Java 7 bytecode checks and 21 isolated dedicated-server scenarios. The scenario mod is not packaged in the runtime. These are subset tests, not the modern branch's GameTests. Consult the attached report and native log for exact runtime evidence.

**Still pending:** advanced display and multipart parity, wireless storage, fluid/energy transport, scripting and installed third-party APIs, real-client visuals, live multiplayer and large-world testing. The branch remains experimental. Newer Java runtime compatibility is not inferred from these tests. Use fresh isolated test worlds or backups; block-ID and player-name ownership differ from modern versions. Do not expose an obsolete test runtime as a public server on the basis of these mod tests.
