# Foundations PL4 1.12.2 - 0.2a-legacy-preview.1

**Experimental initial item-transport subset. NOT full 0.2a parity. Further API testing is still required.**

Native Forge 14.23.5.2864 / Java 8 port with craftable cables, exporters/importers, owner-partitioned physical networks, native sided item handling, inventory-wrapper fallbacks, redstone pause, bounded scans/provider work, and NBT-preserved transfer escrow. Buffered items are released when a host is removed.

Built-in recipe lookup reads actual registered PL4 recipes through `/pl4legacy recipes [page]`. Owner-checked inspection is available via right-click or `/pl4legacy inspect x y z`. These command fallbacks do not require JEI/NEI/Waila; they are not complete graphical substitutes. Rate and scan limits use native configuration.

Publication requires the target's native build and reobfuscation, portable production-rule regressions, and all 21 isolated dedicated-server scenarios. The runtime JAR excludes the scenario mod. These scenarios cover the initial subset, not the modern branch's 191 GameTests.

**Pending:** advanced displays, multipart geometry, wireless network storage, fluids, energy conversion, full scripting/optional integrations, client visual acceptance, live multiplayer and modpack testing. No foreign power API compatibility is fabricated. There is no automatic modern-world migration. Use fresh test worlds or backups.

Compiled implementation is `src/legacy`; `src/main` remains excluded reference source for continuing parity work. See README for crafting, configuration and operation.
