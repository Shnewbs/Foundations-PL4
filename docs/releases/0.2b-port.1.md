# Foundations PL4 1.20.4 Forge — 0.2b-port.1 beta

Performance-only follow-up to the prior 0.2a-port.2 alpha. The network lookup index is retained; each transfer cycle now reuses endpoint target keys in route selection and status counts, avoiding repeated dimension/position/side identifier construction for each candidate comparison. Transfer rates, filters, routing order, ownership, escrow and save schema are unchanged.

This exact Forge target must pass its Java 17 build and 191 native GameTests before GitHub and CurseForge publication. No measured TPS/MSPT improvement is claimed. Installed clients, optional integrations, live multiplayer, large-network benchmarks, migration and complete PL2 parity remain open.
