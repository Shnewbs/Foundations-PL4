# 0.0.2a.R1.4 — Page tools and network transfer caps

- Open Pages with P or the editor HUD button. View all eight fixed page slots and their element counts.
- Copy the current page into an empty slot with fresh element identities while preserving styles, geometry, bindings and layer order. Clear just the current page's contents. Both actions commit atomically and support editor undo/redo; other pages are untouched.
- Add optional server-controlled aggregate item/mB/FE caps per connected data network under `[transfer.networkCaps]`. All Transfer Nodes share a cycle budget, including ADD/REMOVE and escrow retries. Defaults are 0 (uncapped), retaining existing behavior; per-node limits remain.
- Account successful delivery once and bound actual direct insertion offers before committing resources. Keep persistent escrow for any uninserted extraction.

Configuration examples and limits: `docs/TRANSFER_CONFIG.md`.

Native page/security/persistence and item-cap regressions are included, plus core budget boundary tests. Client page-panel visual acceptance and third-party fluid/energy-provider acceptance remain pending. R1.2's user-accepted cable placement fix is retained.

This continues Phase 1. Page names, groups, locks/visibility, layout storage, remaining styling and display actions stay open.
