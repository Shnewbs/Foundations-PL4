# Foundations PL4 1.21.1 — 0.2a.1 alpha

Performance and Wireless Storage UI hardening. Network membership and storage-node lists are indexed at topology rebuild, so storage and reader lookups no longer scan every network group. Transfer rates, filtering, ownership, and routing rules are unchanged.

The Wireless Storage panel fits a 320×240 scaled window: row spacing and footer position adapt to the available height. A new native server scenario opens two independent sessions against one ten-item inventory and verifies conservation when both withdraw from stale snapshots. This uses fake server players and does not certify real two-user multiplayer or client visuals.

The release pipeline runs offline regressions, a NeoForge 21.1.250 build on Java 21, and 192 native GameTests before publishing the runtime JAR, source and checksums. Installed optional APIs, actual client scaling, two-user multiplayer, larger network benchmarks, world migration and full PL2 parity remain open. This is an alpha revision; further API testing is required.
