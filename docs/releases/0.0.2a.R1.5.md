# Foundations PL4 0.0.2a.R1.5

Transfer Nodes now offer explicit native energy and A → B conversion settings, with optional adapters for Mekanism J, GregTech CEu EU, and Electrodynamics through Voltaic, alongside FE. Existing nodes default to native FE. Cables retain the accepted snappy placement behavior.

- **Conversion Off/On**, Input, Output and EU voltage controls in the node Settings tab. Native Input changes also set Output atomically. Only supported installed adapters appear.
- Server/modpack provider switches, conversion permission, independent bidirectional ratios and conversion efficiency. Shared and per-node energy caps use conservative FE-equivalent accounting.
- Sided provider access, EU whole-packet voltage/amperage checks, Electrodynamics advertised-voltage and ampacity checks, simulation before withdrawal, persistent integer escrow and fractional top-up.
- Exact credits and required energy route settings survive node drops and saves. Routes lock while escrow exists; changed ratios pause escrow instead of revaluing it. Electrodynamics' double API uses conservative microjoule rounding, with less than one microjoule loss per actual partial operation.
- One short clickable chat line: **Discord · Support on Ko-fi**. Local client history remembers each Minecraft account across reconnects, deaths, worlds, servers and mod updates. No automatic browser opening or server broadcast.

See [energy setup and server policy](https://github.com/Shnewbs/Foundations-PL4/blob/main/docs/ENERGY_TRANSFER.md) and [transfer caps](https://github.com/Shnewbs/Foundations-PL4/blob/main/docs/TRANSFER_CONFIG.md).

Validation: 30,025 new dependency-free energy assertions passed locally. Publication requires a clean Java 21 native build and all 151 required GameTests; Linux CI runs the full offline and native checks separately. The new provider contract tests use API-shaped fixtures, so installed Mekanism, GTCEu and Electrodynamics/Voltaic modpack acceptance and the new client settings/welcome-line visuals remain pending. Other native power providers and Create rotation are outside this release.
