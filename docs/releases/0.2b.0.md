# Foundations PL4 26.3 — 0.2b.0 beta

Performance-only release. Transfer cycles now reuse each endpoint's physical target key when checking route candidates and reporting eligible peer counts. This avoids constructing the same dimension/position/side identifier for each candidate comparison in larger transfer networks. Routing order, channels, item/fluid/energy rates, filters, ownership, escrow and saved data are unchanged. Existing network lookup caching from 0.2a.1 is retained.

The release gate builds this exact Minecraft and NeoForge target and runs its native GameTests before publishing runtime/source/checksum artifacts. This is a source-level reduction in repeated allocation, **not a measured TPS, MSPT or memory improvement claim**. Installed optional-provider combinations, client scaling, real two-player gameplay, large dedicated-server benchmarks, world migration and full PL2 parity still require acceptance. The beta label describes the release stage and does not certify those open checks.
