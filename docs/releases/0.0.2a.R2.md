# Foundations PL4 0.0.2a.R2 — reader channels and provider foundations

- Pin inventory, fluid, energy, information and network readers to a stable block-face or entity endpoint. Selection survives target reordering and saves; disconnected/unloaded targets do not redirect to another endpoint.
- Target picker and All targets reset, independent of slot/tank/ranked-position modes. Legacy numbered channels remain supported. Picker lists up to 64 endpoints.
- Held-item filter shortcut and clear control for inventory readers and transfer nodes; filter guidance explains tags, allow/exclude and full-storage totals.
- Fluid SLOT now selects the requested zero-based tank. Info Reader key lists trim whitespace; STORAGE no longer overwrites Info Reader telemetry with an empty item counter.
- Public read-only InfoProviders registry with namespaced add-on rows, deterministic ordering, output limits, failure isolation and removable registrations. Existing vanilla keys remain stable.
- Native regression coverage for selection, persistence, provider bounds/failure/cleanup and the production sampling path. Field Guide and developer API documentation updated.

This is the first R2 reader batch. Named channels, combined-inventory deduplication, broader provider integrations and real-client visual acceptance remain follow-up work. Minecraft 1.21.1 and 26.3 have separate builds; the 26.3 CI matrix checks NeoForge 26.3.0.23-beta and 26.3.0.39-beta, not all 26.x binaries.
