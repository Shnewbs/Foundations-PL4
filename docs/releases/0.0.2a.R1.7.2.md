# Foundations PL4 26.3 — 0.0.2a.R1.7.2

Fix dark monitor text and graphics introduced by the native port: use LightCoordsUtil.FULL_BRIGHT packed light coordinates instead of the raw Level.MAX_BRIGHTNESS light level. Covers all text, flat UI graphics, item/block previews, and fluid pictures. Preserve depth testing, layouts, colours, and the cable-per-cell fix from R1.7.1.

The 1.21.1 renderer already uses LightTexture.FULL_BRIGHT and does not require this change. Native compilation, offline regression checks, and GameTests on NeoForge 26.3.0.23-beta and .39-beta gate this release. Client screenshot acceptance remains pending.
