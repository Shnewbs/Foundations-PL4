Recorded October 8, 2026 (America/Los_Angeles; GitHub UTC timestamps are October 9).

## What was ported

The new network-wide Wireless Storage aggregation, query/sort controls, component-aware item variants, withdrawals across stores, offhand deposits, server-side component selection and held-link validation were adapted onto the existing native ports. Target-specific rendering, transfer adapters, item-drop signatures, NBT access and test registration were preserved. Eight new storage/component scenarios were added without removing existing native fixtures. Seven dependency-free migration helper tests also passed; those are not counted as native gameplay tests.

Both versions use Java 25, host save schema 2 and payload protocol 5. Use the exact Minecraft-target JAR and matching client/server versions. Back up worlds. Rebind old reader/display Wireless Storage bindings to a Node or Transfer Node.

## Still open

The additional functional ports for 1.20.1, 1.19.2, 1.18.2, 1.16.5 and 1.12.2, plus experimental 1.6.4, are not completed by this rollout. No new branch for those targets was created in this work. Minecraft 1.7.10 remains excluded; 26.4 remains dependent on a verified target toolchain.

The new optional-API alternatives policy is a completion requirement, not a claim that every alternative or built-in fallback is implemented. Live recipe browsing, fallback task-completeness, version-specific scripting/configuration alternatives, installed-provider behavior, client visuals, multiplayer and sustained-load acceptance remain separately tracked in [API_TESTING.md](../API_TESTING.md) and [MULTIVERSION_PORT_PLAN.md](../MULTIVERSION_PORT_PLAN.md). Missing external systems are not emulated with invented units or capabilities.
