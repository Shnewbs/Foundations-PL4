# R1.10 — reusable display layouts

A combined display workflow update: versioned whole-layout JSON export/import, named local templates, eight-page spatial previews, fit-to-screen placement, fresh import identities, reader-binding controls, and item/fluid/energy starter boards.

Open Layouts in the display editor. Clipboard imports and named loads are previewed before applying. Apply replaces all pages through the existing authoritative server transaction and supports Ctrl+Z. A changed screen revision blocks the preview until reloaded. Fit handles smaller canvases; unavailable reader bindings can be cleared explicitly. Keys remain unchanged and may require adjustment for another network.

Named JSON templates live in config/foundations_pl4/display_templates. Names are restricted, symlink files are rejected, reads are bounded and saves use temporary files with atomic replacement where supported. Save current and Save preview replace the same named file. Delete named removes the local template.

Native regressions cover schema round-trip, starter boards, pages/styles, fresh IDs, smaller-canvas fitting, strict no-fit rejection, unsupported schema, duplicate IDs and oversized payloads. Existing native power, cable and display suites remain required. Client visual acceptance remains separate from server tests.

This release includes previous power/compatibility fixes. Create shaft conversion, native AE transfer, IC2 integrations, server template provisioning and the remaining master-roadmap features are still unfinished.
