# Foundations PL4 1.17.1 0.2a-port.1

Alpha full-feature source port for Minecraft 1.17.1 / Forge 37.1.1 / Java 17.
Retains multipart cable networks, readers, displays/editor, wireless inventory storage,
resource routing and escrow, ownership, field guide and target-native sapphire generation.

Publication requires production-rule checks, native compilation/reobfuscation, exact
resource metadata and 193 installed dedicated-server scenarios. The test-only combined
JPMS module is checked entry-by-entry against the standalone runtime; production-only
startup and shutdown are verified independently without test classes. Actual results are
in `installed-summary.json` and the accompanying logs. Test artifacts are not runtime mods.

**Further API testing is still required.** Client graphics, live multiplayer, optional API
provider combinations and sustained modpack performance remain pending. This does not
claim full PL2 parity or installed acceptance for every upstream provider.

Back up worlds and use matching target-specific client/server builds.
