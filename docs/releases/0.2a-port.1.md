# Foundations PL4 0.2a-port.1 - Minecraft 1.16.4 / Forge

**Alpha target port. Further API testing is still required.**

This is an independently built 1.16.4 target, not a renamed 1.16.5 binary. It carries forward the modern-feature 1.16.5 source baseline: multipart cable/reader/display logic, network item storage, item/fluid/energy transfer and escrow, ownership, and the built-in field guide. It is not the limited 1.6.4/1.12.2 legacy subset.

Target: Minecraft **1.16.4**, Forge **35.1.37**, **Java 17 required** for this PL4 source port. Java 8 compatibility is not claimed. Minecraft metadata is restricted to the exact 1.16.4 target; Forge 36/1.16.5 is not used to certify this build. The payload identity is `forge-1.16.4-5`, separate from 1.16.5.

Publication requires native compilation/reobfuscation, production-rule regressions, resource checks, isolated execution of all 191 original scenarios plus two config regressions on the actual 1.16.4 target, and clean runtime/source packaging. These scenarios are the adapted dedicated-server harness, not modern GameTests. Test classes remain outside the runtime JAR. The native log must independently identify Minecraft 1.16.4.

Real-client rendering, ordinary installed-launcher boot, live multiplayer, installed optional API combinations and sustained performance acceptance remain open unless accompanied by separate evidence. In particular, a successful development server harness does not prove an unmodified older Forge launcher accepts this Java 17 mod. Do not treat this alpha as stable modpack acceptance. No foreign-energy conversion or complete optional-API fallback matrix is claimed.

Back up worlds, remove the previous PL4 JAR and match client/server versions. Do not downgrade worlds or mix different Minecraft targets. The existing 1.16.5 and 1.18.2 branches/releases are retained. 1.18.2 is not omitted from coverage, and the experimental 1.6.4 track remains separate. Minecraft 1.7.10 remains excluded.
