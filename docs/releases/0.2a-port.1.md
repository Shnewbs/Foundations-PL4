# Foundations PL4 0.2a-port.1 — Minecraft 1.14.4

**Alpha. Further API testing is still required.**

This target requires **Minecraft 1.14.4, Forge 28.2.26, and Java 8**. Its source is derived from the full-feature PL4 implementation, not the limited 1.12.2/1.6.4 transport previews. It retains full multipart cables and data networks, wireless item storage, fluid/item/energy routing and saved escrow, owner permission enforcement, reader displays and direct layout editing, forging hammer, guides and sapphire generation.

## Independently gated native checks

The [194/194 isolated native server scenarios](https://github.com/Shnewbs/Foundations-PL4/actions/runs/38018551420) passed on installed Forge28 / Java8, as did exact-target production compilation, scenario compilation, Java8 conversion and archive reobfuscation. No Minecraft/Forge classes or scenario modules are bundled into the runtime JAR.

Local verification on 2026-10-11 repeated all 194/194 scenarios on installed Forge 28.2.26 / Java 8 and completed a separate clean stock-Forge startup and shutdown with only the production JAR. The verified Java 8 runtime SHA256 is `091c205a1dece3399221a8aaee055ccf61a5f28309bc33097f67a01bf4a5057e` from source commit `5a28dfc2a8516d8b9aaf040f4ca6652ea02c796f`. This verifies the local artifact; publication remains pending.

The original cable, world-space display, item/fluid picture rendering, editable monitors and animated multi-box hammer were adapted to Forge28's native renderer; they were not removed to make the port compile.

## Important alpha limitations

These tests are isolated installed-server scenarios, not modern Minecraft GameTests. **Real-client visuals and interaction, third-party installed optional APIs, multiplayer and sustained performance tests remain pending.** No foreign energy conversion is guessed where an API is unavailable. Neither complete PL2 parity nor stable modpack compatibility is certified.

Install only the exact 1.14.4 runtime JAR on both client and server, not sources or Java8 intermediate archives. Back up worlds before testing. The release preserves the licensing notices, JvmDowngrader matching upstream source, and reproducible source build inputs.

**Further API testing is still required.**
