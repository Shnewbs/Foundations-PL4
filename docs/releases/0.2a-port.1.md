# Foundations PL4 1.18 — 0.2a-port.1

**Alpha candidate. Minecraft 1.18 / Forge 38.0.17 / Java 17.**

The full PL4-derived Forge source retains cables, readers, displays, editing,
wireless inventory storage, items/fluids/energy, safety escrow, hammer crafting
and native sapphire overworld generation. Release is conditional on native
compilation and 193/193 installed Forge38 GameTests; a relabeled 1.18.1 binary
is not compatible.

Local verification on 2026-10-11: all 193 native GameTests passed on an
installed Minecraft 1.18 / Forge 38.0.17 dedicated server. A separate test
module supplies Forge 38's class-prefixed empty SNBT structures and advances
the vanilla GameTest ticker. The standalone production JAR excludes all test
classes; 881 production entries matched the test module byte for byte. The
production JAR alone booted and shut down cleanly. Runtime SHA-256:
`4c50714530bd3fc12ac85c8bcd2bc0298ca92a7c0a17c2ba1da6afbe3b01a58a`.
See `verification-logs/installed-118-summary.json` in the local build bundle.

**Further API testing is required** for graphical rendering, installed optional
providers, multiplayer and sustained modpack performance.
