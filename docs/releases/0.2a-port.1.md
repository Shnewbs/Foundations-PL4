# Foundations PL4 1.15.2 0.2a-port.1

Alpha feature port for Minecraft 1.15.2 / Forge 31.2.62 / Java 8.
Build source uses Java 17 with build-time compatibility conversion before reobfuscation.
No runtime agent or external helper mod is needed. Minimal relocated compatibility
classes, LGPL notices and matching upstream source are included with the release.

Carries the modern-derived multipart/cable, reader/display/editor, wireless inventory
storage, item/fluid/energy routing and escrow, ownership, field guide and sapphire
implementation. Uses the actual Forge 31 dimension, NBT, recipe and rendering contracts.
Strict native JSON serialization replaces unavailable modern codecs. Forge's native
optional-tag array retains optional material aliases without breaking vanilla fallbacks.
Saved parts strip both long-pair UUID fields and newer UUID keys, keeping meaningful
configuration/escrow but never the former owner or runtime identity.

Publication requires production-rule regressions, exact metadata/resources, Java 8
archive checks and all 194 scenarios on installed Forge with the packaged runtime.
The suite retains the original 191 scenarios plus native sapphire attachment, strict
optional JSON-field validation, and the real ItemStack entity-transceiver interaction.
Check the attached java8-summary.json and native log for actual acceptance; this note
alone does not claim testing has completed. Scenario classes are not runtime assets.

**Further API testing is still required.** Installed third-party provider combinations,
real-client graphics, live multiplayer and sustained modpack performance remain pending.
This port does not certify full PL2 parity or arbitrary foreign-energy API compatibility.
Back up worlds, install only the matching published runtime JAR, and update client/server together.
