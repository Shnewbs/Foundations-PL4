# Foundations PL4 1.15.2 0.2a-port.1

Full modern-derived feature port targeting Minecraft 1.15.2 / Forge 31.2.62.
Java 17 build source is converted to Java 8 and reobfuscated before packaging.
The existing multipart, reader/display, wireless storage, transfer, ownership and guide
implementations are preserved. A branch is not a successful runtime port.

Release requires all production rule checks, native compilation, Java 8 archive validation
and the complete 191-scenario suite on installed Forge with the actual packaged runtime.
Runtime artifacts exclude scenario classes. Required compatibility-helper license and source
assets accompany the release.

**Further API testing is still required.** Client visuals, multiplayer, installed API mods and
long-running performance remain pending. Back up worlds and match client/server builds.
