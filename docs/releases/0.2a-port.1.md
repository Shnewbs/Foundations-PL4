# Foundations PL4 1.19 / Forge41 — 0.2a-port.1

Native Forge 41.1.0 target, derived from full 1.19.1 source with multipart
cables, displays/editor, energy/fluid/item transport, wireless item storage
and saved escrow.

Locally verified on 2026-10-11: the production JAR built with Java 17; an
isolated scenario JAR passed 191/191 native GameTests on installed Forge
41.1.0. The verifier compared 878 production entries with the release JAR,
then booted and shut down a fresh server with only the production JAR.
Production SHA-256:
`9c1be24c7d1cd4dba73ed9a0ff0b89d7c07ce1e4258d043bd9e3c3c74aad6848`.

This is an interim alpha port. The requested 0.97.0.rev1-beta release and
direct CurseForge submission are pending. Further installed optional API,
real-client and multiplayer testing is needed.
