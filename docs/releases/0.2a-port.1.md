# Foundations PL4 1.17.1 0.2a-port.1

Alpha port of the current modern-source feature baseline: cables/multipart topology,
readers, displays/editor, wireless inventory storage, transfer routing/escrow, ownership,
field guide and native sapphire generation. Uses exact Minecraft 1.17.1 / Forge 37.1.1
and requires Java 17 for this build.

Release is gated on native compilation/reobfuscation, standalone resource checks,
production rule regressions and all 193 registered native tests. Check the attached
native log for actual acceptance; this note itself does not claim tests have run.

**Further API testing is still required.** Real-client visuals, multiplayer,
installed-provider combinations and long-running performance tests remain pending.
This does not certify full PL2 parity. Back up worlds and match client/server builds.
