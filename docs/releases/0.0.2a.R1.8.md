# R1.8 — pushed power interoperability

Transfer Nodes now expose a sided, receive-only NeoForge FE capability. External generators and energy cables can push FE into a REMOVE or ADD/REMOVE node; configure Energy on and Input FE. Accepted power enters the existing persistent conversion escrow and is routed to matching destinations. Simulation is read-only, disabled or removed nodes reject cached handlers, and storage is bounded by the server node energy limit. Conversion policy and saved ratios remain enforced.

Multipart changes now invalidate NeoForge capability caches so neighboring automation can discover added and removed node interfaces.

Includes the previously released cable placement fixes; the 26.3 build also includes the full-bright screen and FML configuration compatibility fixes.

Validation: native fixture covers capability discovery, simulation, exact escrow accounting, full-buffer rejection, mode changes and cached-handler revocation. Optional third-party mods are not installed in CI; actual modpack acceptance remains to be tested. This adds standard FE interoperability, not AE2 grid energy, IC2 power or Create stress conversion.
