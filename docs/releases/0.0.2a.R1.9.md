# R1.9 — Create kinetics and AE2 grid monitoring

Energy Readers now offer CREATE and AE2 modes with dedicated model carriers and original brass/gear and purple/grid textures. Use the existing crafted reader; changing its mode selects the model automatically, including covered-reader placement.

Create rows: signed RPM, theoretical RPM, network stress/capacity and overstress. AE2 rows: native AE storage/capacity, average usage/injection and powered state. Multiple nodes on the same AE2 grid are counted once. Missing APIs, disabled adapters and unloaded targets produce explicit status; the adapters are optional and read-only.

Server controls: energyReader.createKinetics and energyReader.ae2GridEnergy. Selection persists across saves and existing client synchronization. API contract regression tests and native model/selection fixtures are included.

This release monitors Create rotation and AE2 grid power; it does not implement shaft torque transfer or AE grid conversion. IC2-specific APIs and the remaining integration/product backlog remain tracked in docs/INTEGRATION_STATUS.md and the master roadmap. A supported official Create 26.3 runtime has not been verified. CI validates standalone PL4 and synthetic API contracts, not installed Create/AE2 gameplay or client visuals.
