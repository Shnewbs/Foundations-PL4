# Foundations PL4 0.0.2a.R1.1

Display selection workflow continuation for Minecraft 1.21.1 / NeoForge / Java 21.

- Drag empty monitor space to select a box. Reverse drags work; selection includes overlapping elements on the current page. Shift adds to a box or toggles individual elements; Ctrl+A selects the current page.
- Drag a selected element to move the whole selection. All elements share one displacement, preserving sizes and spacing at canvas edges. Corner handles resize the active element.
- Ctrl+C/V copies and pastes an entire selection, including styles. Ctrl+D duplicates it. Paste targets the current page and applies a shared 4px offset, clamped to canvas edges.
- Batch moves and pastes commit once, are revision fenced, and retain ownership, reach, joined-canvas and reader-visibility checks. Capacity or invalid-selection failures leave the whole batch unapplied. One undo restores the whole operation.
- CurseForge publication uses the official version-name metadata, including required Client and Server environments. Existing GitHub releases can be uploaded using the checksum-verified backfill workflow.

Publication requires the offline regression checks, clean native build and GameTests to pass. Client visual acceptance of marquee/drag behavior is still pending. Freeform lasso, persistent grouping/locking, named pages, templates and the remaining R1 styling/action work remain on the roadmap.

Install the regular mod JAR. Sources, full tracked-source ZIP and SHA-256 checksums are also included in the GitHub Release.
