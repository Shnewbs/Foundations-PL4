# Foundations PL4 0.0.2a.R1

First public 0.0.2a alpha continuation for Minecraft 1.21.1 / NeoForge 21.1.250 / Java 21.

## Display editor

- Per-element text alignment, 25%–400% scale and bounded line wrapping, persisted through NBT and JSON.
- Shift-click multi-selection, atomic multi-delete, copy/paste and selected-element duplication.
- Ctrl+Z undo and Ctrl+Y / Ctrl+Shift+Z redo using revision-checked whole-layout snapshots.
- **Arrange [A]**: align left, right, top, bottom or centres. One selected element aligns to the canvas; multiple elements align to their combined bounds.
- Horizontal/vertical equal edge spacing for at least three elements on the current page. Outer anchors stay fixed, and insufficient space is rejected.
- Arrangement uses server canvas dimensions and enforces existing ownership, reach, chunk and joined-canvas checks. Other pages and element styles remain unchanged.

## Cable and performance work

- Place new cable along the aimed cable arm and publish nearby connection geometry immediately.
- Reduce idle cable serialization, repeated sampling/transfer work, filter parsing and render-loop allocations.
- Preserve the accepted R17 wall/floor/ceiling hologram positioning and passive Transfer Node safeguards.

## Validation and remaining scope

Publication requires a clean Java 21 build, offline regression/resource checks and native GameTests. Arrangement tests cover style conservation, unselected-page isolation, stale revisions, invalid identities, ownership and equal spacing.

This release implements part of the R1 display/GSI roadmap. Element containers/actions, full styling, box selection, grouping/locking, named pages and layout templates remain planned. Client visual acceptance of the new arrangement panel and wrapping is still required; automated checks do not establish exact graphical parity.

## Downloads

Install the regular mod JAR. The sources JAR and complete-source ZIP are for development; the ZIP includes the roadmap, documentation, assets and build scripts. `SHA256SUMS.txt` covers every downloadable build artifact.
