# Foundations PL4 26.3 — 0.0.2a.R1.6-port.2

Fix startup on NeoForge 26.3.0.39-beta: newer FML replaces the SERVER config type with SYNCED. Resolve the server-synced config type by name while retaining the foundations_pl4-server.toml filename. Do not fall back to an unsynced config.

Native build and GameTests must pass on both NeoForge 26.3.0.23-beta and 26.3.0.39-beta before publication. The config API audit checks published 1.21.1 and 26.x loader variants; this does not establish whole-mod compatibility with other Minecraft versions. Client visual acceptance and third-party power providers remain unverified.

Requires Minecraft 26.3 and Java 25. Install the regular mod JAR.
